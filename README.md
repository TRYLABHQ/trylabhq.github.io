# trylabhq.github.io

TRYLAB GitHub Pages 저장소입니다. `main`에 올린 HTML이  
[https://trylabhq.github.io/](https://trylabhq.github.io/) 로 공개됩니다.

## 링크 규칙

조직 사이트라서 주소는 저장소 폴더/파일 경로가 그대로 붙습니다.

`https://trylabhq.github.io/` + `폴더명/파일명.html`

## 공개 페이지

| 문서 | 파일 | GitHub Pages |
|------|------|----------------|
| bbop 개인정보처리방침 | `privacy-policy/bbop.html` | [https://trylabhq.github.io/privacy-policy/bbop.html](https://trylabhq.github.io/privacy-policy/bbop.html) |
| Pickleon 개인정보처리방침 | `privacy-policy/pickleon.html` | [https://trylabhq.github.io/privacy-policy/pickleon.html](https://trylabhq.github.io/privacy-policy/pickleon.html) |
| Pickleon 이용약관 | `terms-of-use/pickleon.html` | [https://trylabhq.github.io/terms-of-use/pickleon.html](https://trylabhq.github.io/terms-of-use/pickleon.html) |

앱 스토어·인앱 링크에는 위 GitHub Pages URL을 사용하면 됩니다.
